# General Agent Runtime production hardening ledger

This ledger is the delivery authority for the production review performed on
2026-07-21. A finding moves to `complete` only after its invariant is enforced
in the current implementation, a regression test covers the original failure
path, legitimate behavior remains covered, and the listed verification command
passes.

Statuses:

- `open`: no verified repair yet;
- `in_progress`: implementation or proof is being developed;
- `complete`: implementation and verification evidence are recorded here;
- `blocked`: a named external decision or dependency prevents further work.

## Verification policy

Every completed row must record:

1. the source-to-sink failure or broken invariant that was reproduced;
2. the enforcement boundary selected for the repair;
3. the focused regression test and legitimate control;
4. the relevant package/type/static tests;
5. any remaining operational proof that cannot run locally.

The final completion audit must also run the full Python suite, TypeScript type
check, production dependency audits, and the real mainland Provider acceptance
suite with `OPENAI_API_KEY` absent.
